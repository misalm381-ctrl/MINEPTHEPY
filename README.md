# MINEPTHEPY – Movie Recommendation System

## Project Overview

MINEPTHEPY is a Python-based movie recommendation system built using the MovieLens dataset. It uses exploratory data analysis, content-based filtering, and collaborative filtering to help users discover movies.

## Features

* MovieLens dataset loading and cleaning
* Exploratory Data Analysis (EDA)
* Movie rating and genre visualizations
* Popular movie recommendations
* Content-based recommendations using TF-IDF
* User-based collaborative filtering
* Interactive movie search and recommendation menu
* Model evaluation and output export

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab
* MovieLens dataset

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Allow the notebook to download and process the dataset.
4. Use the interactive menu to explore movies and generate recommendations.

## Dataset

The project uses the MovieLens Latest Small dataset.
